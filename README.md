# 天空星 PWM 呼吸灯

适用白色立创天空星STM32F407VxT6，板载绿色LED=PB2高电平亮，KEY=PA0高有效。默认开机进入3秒周期呼吸。

## 操作

- 短按KEY并松开：呼吸 → 双心跳 → 萤火虫 → 常亮 → 呼吸。
- 长按KEY约0.8秒：最大输出占空比100% → 35% → 10% → 100%；长按松开不会再切换模式。
- KEY采用25ms软件消抖。不要操作RST/BOOT0做灯效切换。
- 呼吸采用余弦包络并平方补偿；心跳为两次不同强度的渐变脉冲；萤火虫为平滑随机明灭。无浮点实时运算。

## PWM实现

PB2没有TIMx_CHy硬件PWM复用，因此TIM3在PA6/AF2/CH1生成真正硬件PWM，同时TIM3更新/比较中断镜像驱动PB2。现有板载LED无需改线。需要测硬件PWM时，用示波器测PA6对GND；不要把PA6与PB2直接短接。

168MHz主频下TIM3计数1MHz，PSC83，ARR999，载波1kHz，占空比0..1000。CCR预加载，仅周期边界更新，软件镜像存在中断响应延迟，不属于纯硬件输出。极低亮度使用至少4us脉冲跨周期分配，避免PB2过短脉冲被ISR延迟吞掉。0%/100%单独处理。SysTick与UART不会抢占TIM3；曲线每5ms更新。

PA6硬件PWM输出与PB2有微小边沿时差，不能把板载LED输出当作精密时序源。此程序用于LED演示。

## 串口（可选）

PA9 → DAP RXD，GND共地；COM16，115200 8N1。每500ms发送当前模式、目标占空比、亮度上限、周期和暂停状态。

若再接DAP TXD → PA10，可发送单字符：1/2/3/4选择模式；空格暂停/继续亮度变化；b切换亮度上限；+加快、-减慢周期（1.5~6秒）。板载KEY不需要串口接线。
